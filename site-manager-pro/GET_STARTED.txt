🚀 QUICK START (9 STEPS)

1. Create GitHub account (FREE)
   → Go to github.com
   → Sign up with email
   → Verify email

2. Create Expo account (FREE)
   → Go to expo.dev
   → Sign up with email
   → Verify email
   → SAVE YOUR LOGIN!

3. Download all files from outputs
   → Extract/unzip them
   → Keep all files together

4. Create GitHub Repository
   → Log in to GitHub
   → Click "+" → "New repository"
   → Name: "site-manager-pro"
   → Upload all files

5. Get Expo Token
   → Log in to Expo
   → Account → Tokens
   → Create new token
   → Copy the token

6. Add to GitHub Secret
   → Go to repository Settings
   → Secrets and variables → Actions
   → New secret
   → Name: EXPO_TOKEN
   → Value: Paste token

7. Build in Cloud
   → Go to Actions tab
   → Click "Build APK"
   → Click "Run workflow"
   → Wait 10-15 minutes

8. Download APK
   → When done, click workflow
   → Download from Artifacts

9. Install on Phone
   → Connect to phone (USB/Email/Messaging)
   → Transfer APK file
   → On phone: File Manager → APK → Install
   → Done! 🎉
